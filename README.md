# MiniCraft on STM32N6570-DK

自制第一人称体素沙盒，运行于 STM32N6570-DK。256×64×256 世界存于外部 PSRAM，Cortex-M55 将 160×96 软件渲染画面放大至 800×480 LCD；GT911 触屏控制，FileX 读写 SD 卡。

## 当前功能（v5）

- 地形、树木、水、矿洞、煤铁矿；挖掘、放置、碰撞、跳跃、游泳、潜行防跌落和两个独立世界。
- 32 格背包，前 8 格为快捷栏，每格最多 64；支持点选移动、拆分、合并、交换及满包保护。7 类工具有独立耐久，镐按材质分级，斧铲加速对应采集。
- 34 项配方、工作台、6 个箱子（各 24 格）、6 个定时熔炉、最多 16 株可生长树苗、耕地与小麦种植、床与重生点、可开关木门、上下半石台阶、四向石楼梯和木围栏；新增弓箭远程战斗与四件铁质护甲。小麦可合成面包，生肉可在熔炉加工成熟肉。护甲可在背包底部穿戴/卸下，提供减伤并会损耗耐久。熔炉每件加工约 5 秒，需输入、燃料和输出空间。
- 20 点生命、20 点饥饿；苹果、生肉、面包和熟肉恢复生命与饥饿，饥饿会随生存时间下降，归零后造成伤害；跌落与缺氧伤害、保留背包重生；600 秒昼夜。最多 8 个夜间敌人和 4 只白天被动动物，动物会漫游、逃跑、被小麦吸引、繁殖并掉落生肉；露天敌人在天亮时消失，黑暗洞穴中的敌人保留；近战冷却、武器伤害和耐久、受击反馈；附近有敌人时不能睡觉。
- 经验等级 0～30：采煤、采铁、采集木材/石材、制作、熔炉加工和击杀可获得经验；等级 5 和 15 分别增加 1 点武器伤害，等级与经验会随 v4 存档保存。
- 原创 16×16 透明物品图标，覆盖背包、快捷栏、合成、箱子和熔炉，并在右下角按物品轮廓比例显示当前手持物品（火把、树苗、肉、面包、剑、工具、弓箭、护甲、围栏、楼梯、种子、小麦和红石元件等不再统一拉伸）。67 个图标条目共占 10720 字节 ROM，无运行时 SD 图像读取。
- 沙子具备有界重力：玩家附近 13×13 区域低频检查，每次最多处理 12 格；悬空沙子逐格下落，受支撑沙子保持，运行时调度器不改变 v4 存档布局。

火把使用宽深 4/16 格、高 10/16 格的杆体，火焰由 4/16、3/16、2/16 宽的三段阶梯组成，总高 14/16 格；树苗使用透明交叉面。箱子宽深及高为 14/16 格，四周内缩；床高 9/16 格。选取和渲染遵从同一组实际部件轮廓，床/箱子碰撞与支撑高度一致，火把/树苗可穿行。火把内部重叠接缝不会被选中。

## 操作

- 上电先显示主菜单：两个世界槽中，有效存档显示 `CONTINUE`，空槽显示 `CREATE`。创建页可点种子切换地图，点模式切换生存/创造，再点 `CREATE WORLD` 进入；新世界立即保存到空槽。已有存档和异常文件占用的槽位不会被新建覆盖；两槽都已占用时只能继续现有世界。无 SD 卡时可创建临时世界。

- 左下摇杆移动，场景拖动转向，右侧 `JUMP` 跳跃／水中上浮；按住 `SNEAK` 减速并防止走出平台。
- 没有挖掘按钮。在场景方块上按住约 450ms 开始挖掘，按硬度持续开采；拖动超过 12 像素重新计时，停止拖动后仍可长按挖掘。挖掘目标是手指位置，最远 5 格。
- 场景短按抬手执行放置、使用、进食或攻击；持续按住约 450 ms 直接开始挖掘，不会先放置/吃东西，手持方块、材料和食物也可挖掘。弓的长按仍用于连续射击。右侧只保留潜行、跳跃等必要控制。攻击不占用独立按键，手持剑、斧或镐点击场景即可攻击准星敌人，手持弓点击场景发射箭，长按场景可按冷却持续射击；场景长按挖掘仍由场景触摸触发。选苹果、生肉、面包或熟肉时通过场景操作恢复生命和饥饿。生存模式饥饿约每 30 秒下降 1 点，归零后约每 2 秒受到 1 点伤害。弓需要箭并有耐久，箭会撞击方块或生物后消失。当前手持物品会显示在右下角图标框。
- 手持铲子点击草地或泥土可锄成耕地；手持小麦种子点击耕地播种。小麦约 75 秒成熟，成熟后长按收获小麦和种子；种子也可由草方块低概率掉落。
- 红石入门已加入红石粉、红石灯、拉杆和按钮：拉杆持续供电，按钮产生约 0.5 秒脉冲，红石粉在玩家附近用固定 128 节点预算传播并点亮相邻红石灯；红石元件有独立图标和按比例的手持显示。
- 手持小麦点击准星指向的被动动物可喂食并吸引它靠近；两只已喂食且距离不超过约 2.6 格的动物会生成幼体。喂食窗口约 20 秒，繁殖冷却约 12 秒，动物总数上限为 4；右侧只保留通用 `PLACE`/`USE` 区域，不提供独立攻击键。
- 底部点选快捷栏。`BAG` 打开背包，点来源再点目标移动／合并／交换，`HALF ON/OFF` 切换拆分；箱子支持背包与容器转移。熔炉点来源物品后点输入／燃料槽，点输出槽取出。
- 生存背包右下方提供头盔、胸甲、护腿和靴子四个装备槽；点背包中的铁质护甲即可穿戴，点击装备槽卸下。护甲值和耐久条会显示在装备槽下方，背包满时拒绝卸下并保留已穿戴装备。
- 制作栏点配方制作，顶部翻页；工作台须在附近。加工配方通过熔炉输入和燃料执行。菜单暂停物理、敌人和游戏时钟。
- 场景右上角显示局部小地图：地表颜色、玩家朝向、床的出生点和已放置箱子都会标出；地图随挖掘、放置和移动即时更新，不占用存档空间。
- 新世界会在远离出生点的平坦高地生成最多 2 座小型石砖遗迹；遗迹保留开放入口、火把和可打开的奖励箱，箱内提供火把、煤、苹果和石镐。遗迹箱子复用现有 v4 容器字段，同种子位置和奖励稳定。
- 背包可切换生存／创造；创造目录先选快捷栏位置，再点物品；点击左侧目录标题翻页，可选择全部可用物品。生存从空背包开始：原木 → 木板／木棍／工作台 → 木镐 → 圆石 → 石镐／熔炉 → 铁。
- `SAVE` 手动保存；有变化时每 30 秒自动保存。背包 `MENU` 保存后返回主菜单，再选择继续或创建世界；写入失败时保留当前游戏。

## 存档

v5 单档 4,195,904 字节，保存地图、背包、工具、四件护甲及耐久、容器、加工、生长、重生点、昼夜、敌人状态、经验和等级；护甲及 XP 沿用原元数据预留区，地图扩容后文件尺寸随之增加，支持 v1/v2/v3/v4 读取迁移。旧 v4 存档没有 XP 标记时按 0 XP 加载。旧地图不会自动插入新矿物或洞穴，可进入另一世界生成新图。

- 世界 1：`MC0.SAV`／`MC1.SAV`；世界 2：`MC2.SAV`／`MC3.SAV`。双槽轮换、CRC 和写后回读校验。
- 单槽损坏时用另一个有效槽；无有效槽但发现异常文件，或发现未来版本时，保护为只读。没有 SD 仍可玩，断电不保留。
- `initial-world-v5.SAV` 是预览生成的示例，勿覆盖自己的存档。开发脚本的 `--sd G:/` 只读 SD。

## 构建与烧录

需要 Python 3.10+、ARM GNU 工具链和 STM32CubeProgrammer 的 SigningTool。仓库仅保留游戏构建实际使用的应用和 SDK 文件，不包含 ISP 库、IDE 缓存、固件和存档。原 CubeIDE 工程元数据仅作为源文件列表使用；以 Python 脚本构建为准。

```powershell
python tools/build_minicraft.py --toolchain "F:/path/to/arm-gcc/bin" --signer "F:/STM32CubeProgramer/bin/STM32_SigningTool_CLI.exe"
```

本机默认路径可省略参数。输出位于 `out/minicraft/`。编译定义 `MINICRAFT_GAME_ONLY` 排除未使用的相机 ISP，保留板级初始化。

| 输出 | 写入地址 |
| --- | --- |
| `MiniCraft_N6-Trusted.bin`（含 0x400 字节头） | **0x70100000** |
| `MiniCraft_N6.bin`（裸应用） | 0x70100400 |

两种应用文件选择一种烧录。沿用已正常启动本项目的 FSBL（地址 0x70000000，XIP 偏移 0x100000、头偏移 0x400）；本仓库不提供 FSBL 构建。首次配置开发板需先准备兼容该布局、完成 PSRAM／外部 Flash 初始化的 FSBL。

## 检查、预览与回溯

```powershell
python tools/test_minicraft.py --sd G:/
python tools/snapshot_minicraft.py
```

主机 GCC 以 `-Wall -Wextra -Werror` 验证几何、移动、采集、掉落、背包、合成、容器、熔炉、生长、战斗和存档；ARM 构建验证链接与签名。快照脚本在构建后生成精简源码 ZIP、固件副本、哈希与验证记录，保存到 `out/verified-v22/`。预览工具 `tools/minicraft_preview.c` 共用固件渲染器，可生成场景、界面和农业预览，包括按手持物品变化的攻击、射击、喂食、建造和进食提示。

用户此前旧版板上约 15 FPS；**当前 v22 尚未烧录实测**。主机预览不能证明板上性能；触屏多指、LCD、真实 SD 迁移、异常断电和长时间运行仍需板验。

## 当前限制

火把仅直立，床仍为单格；敌人已能跳上单格障碍，支持洞穴黑暗生成、露天黎明清除和箭矢战利品；仍无全局寻路和行走动画。弓箭使用最多 8 个运行时投射物槽，箭不写入 v4 存档，加载存档时清空。动物暂只有一种，繁殖状态是运行时状态，加载 v4 存档后重新清零。农业当前只有小麦一种作物；已有附近有界水流，岩浆、音效与联网仍未实现。红石传播只覆盖玩家附近的有界区域，板上长时间平衡仍待验证。沙子重力目前只覆盖玩家附近的有界区域，板上长时间平衡仍待验证。饥饿循环已加入，板上长时间平衡仍待验证。背包有空间时采集物直接入包；背包无法接收时会生成最多 16 个运行时掉落实体，掉落物受重力落地、同类合并、靠近自动拾取并在 300 秒后清除。掉落物不写入 v4 存档，加载存档时清空。

## 建筑部件

木围栏由立柱和上下横杆组成，石楼梯支持四个放置朝向。两者的碰撞、射线选取、放置和渲染使用实际部件几何；背包和创造目录只显示基础石楼梯，挖掘方向状态后统一掉落基础石楼梯。配方为 `4 PLANKS + 2 STICKS -> 3 FENCES` 和 `6 COBBLE -> 4 STONE STAIRS`。

完整清单和下一步见 [玩法路线图](docs/MINICRAFT_GAMEPLAY_ROADMAP.md)。第三方来源与许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 渲染性能优化（v13）

- 空气射线步进跳过特殊形状判定；地形遮住天空时跳过日月/云/星计算。实体先按屏幕行剔除，仅遍历有效实体位图。
- 水面纹理每帧按需计算 256 个纹理值；附近灯光以方块坐标缓存，每帧重建，保留即时照明变化。小地图在边界检查后直接扫描地图列。
- 保持 160×96 世界分辨率和 40 格渲染射线参数。主机基准固定四类场景、每类 32 帧、交替运行三轮，以逐帧 CRC 对比旧版画面。耗时仅用于主机算法对比，不代表板上 FPS。
- 复现：`python tools/bench_minicraft.py --baseline 9011b91`；报告在 `out/minicraft/perf/comparison.json`。带性能报告归档：`python tools/snapshot_minicraft.py --benchmark-baseline 9011b91`。比较旧版源码需要保留 Git 历史。

红石更新在地图未改变且玩家未跨格时复用电路结果；方块编辑、按钮释放、跨格移动、生成和读档会使结果失效。缓存仅为运行时状态，v4 存档格式保持不变。基准工具另测静止、编辑和移动三类世界更新场景，每个采样组模拟 64 次更新并比较地图 CRC；可用 `--baseline d9b8cea` 单独比较 v13 与 v14。

游戏左上角只显示坐标、帧率和最长帧耗时，保留背包/保存按钮、小地图和操作反馈；不显示常驻状态日志。

## 建造与精简信息行（v17）

- 左上角仅显示 X/Y/Z、FPS 和最长帧耗时 MAX（毫秒）；不显示常驻状态日志和昼夜文字。
- 手持石台阶点下半台阶的顶面，或上半台阶的底面，可消耗一个台阶合成整格双台阶；从侧面往相邻半台阶的空半格放置也能合并。会填进玩家身体时拒绝操作。双台阶占满一格，使用镐采集掉落两个石台阶，复用原配方；内部地图 ID 不出现在背包或创造目录。
- 非中心触点放置统一使用该触点射线；台阶上下半格选择按实际命中高度计算。两件掉落的空间不足时不部分生成，避免满包后重复采集刷物品。旧 ID 保持原编号；本次随 v18 一并交付，地图使用 v5 存档。

## 简中与扩大地图（v18）

- 游戏 UI 使用简体中文：主菜单、创建世界、物品/配方、背包/箱子/熔炉、战斗、种植、提示均接入词条；数字及 X/Y/Z 等坐标标记保留。字库为固件内置 12/16 像素点阵，只包含已使用汉字，无需从存储卡加载。
- 地图扩大为 256×64×256，共 4,194,304 格，水平面积为旧版四倍；地图与保存缓冲合计约 8 MiB，仍位于 16 MiB PSRAM 内。视距、世界画面分辨率及附近系统更新窗口保持原设置。
- 新文件版本为 v5；旧 128×64×128 的 v1-v4 存档保留原坐标、方块、背包和容器，向原区域外生成新地形。迁移后的世界按 v5 保存，旧固件不能读取该新档；双槽保留迁移前备份，历史 out 快照继续保留。
- CRC 保持 IEEE CRC-32 格式，改用半字节表降低大地图校验成本。补充旧尺寸真实布局迁移、越界元数据拒绝及旧区域逐行一致性测试。
- 简中资源：`tools/minicraft_zh.json`，生成器：`tools/make_minicraft_zh.py`。使用的 Noto Sans SC 字形子集及 OFL 许可说明见 `THIRD_PARTY.md`。完整上游字体仅下载至 out，不上传。

## 洞穴威胁与敌人越障（v19）

- 白天能直达天空的位置不会生成敌人；不透光顶棚下的黑暗空间可生成。玻璃允许天光通过，附近火把或通电红石灯阻止生成。动物只在白天露天草地生成。
- 黎明只清除露天敌人，地下或屋顶下的敌人保留；人工照明只阻止新生成，不清除已有敌人。存档仍为 v5，读档后继续按环境更新。
- 敌人追击时可起跳越过一格高的障碍；同时检查起跳上方和落点空间，两格墙与低顶仍阻挡。物理碰撞按 20 毫秒分步，实体逻辑为 10 Hz，上限仍为 8，不扫描整张地图。
- 主机回归覆盖昼夜、洞穴/玻璃/火把/红石灯、真实定时生成、洞穴敌人读档、露天清除无奖励、一格越障、两格墙与低顶阻挡。预览与固件存于 out/verified-v19；实机触控和帧率仍待验证。

## 保存结果反馈（v20）

- 不增加 Log 栏：保存按钮原位显示“保存中”“已保存”“无存储卡”“只读”“写入失败”或“校验失败”，使用黄/绿/红色文字和短横线；左上角仍仅显示坐标、帧率和最长帧耗时。
- 成功提示约 3 秒，错误约 6 秒后恢复“保存”；背包内同样可见，暂停游戏不会冻结反馈计时。“已保存”仅在双槽写入及回读校验通过后显示；失败时保留旧有效槽。无卡新建世界也显示提示。
- 按钮反馈仅为运行时状态，不增加存档字段；切换世界或读档后清零。主机测试覆盖所有结果、提示过期、背包暂停和长帧计时、画面仅改变按钮区域、编解码字节不受反馈影响。固件与六种状态预览保存到 out/verified-v20；真实 SD 故障和 LCD 效果仍需板验。

## 创造目录翻页（v21）
