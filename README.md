# MiniCraft on STM32N6570-DK

自制第一人称体素沙盒，运行于 STM32N6570-DK。128×64×128 世界存于外部 PSRAM，Cortex-M55 将 160×96 软件渲染画面放大至 800×480 LCD；GT911 触屏控制，FileX 读写 SD 卡。

## 当前功能（v4）

- 地形、树木、水、矿洞、煤铁矿；挖掘、放置、碰撞、跳跃、游泳、潜行防跌落和两个独立世界。
- 32 格背包，前 8 格为快捷栏，每格最多 64；支持点选移动、拆分、合并、交换及满包保护。6 类工具有独立耐久，镐按材质分级，斧铲加速对应采集。
- 17 项配方、工作台、6 个箱子（各 24 格）、6 个定时熔炉、最多 16 株可生长树苗、床与重生点。熔炉每件加工约 5 秒，需输入、燃料和输出空间。
- 20 点生命、苹果恢复、跌落与缺氧伤害、保留背包重生；600 秒昼夜。最多 8 个夜间敌人，近战冷却、武器伤害和耐久、受击反馈；附近有敌人时不能睡觉。
- 原创 16×16 透明物品图标，覆盖背包、快捷栏、合成、箱子和熔炉。图标共占 4960 字节 ROM，无运行时 SD 图像读取。

火把使用宽 2/16 格、高 10/16 格的细杆，火焰宽 4/16 格、顶部高 13/16 格；树苗使用透明交叉面。箱子宽深及高为 14/16 格，四周内缩；床高 9/16 格。选取和渲染遵从实际轮廓，床/箱子碰撞与支撑高度一致，火把/树苗可穿行。火把内部重叠接缝不会被选中。

## 操作

- 左下摇杆移动，场景拖动转向，右侧 `JUMP` 跳跃／水中上浮；按住 `SNEAK` 减速并防止走出平台。
- 没有挖掘按钮。在场景方块上按住约 450ms 开始挖掘，按硬度持续开采；拖动超过 12 像素取消长按。挖掘目标是手指位置，最远 5 格。
- `USE` 根据准星目标打开箱子、熔炉、工作台或使用床；否则放置选中方块。选苹果时显示 `EAT`。`ATTACK` 攻击准星敌人，长按敌人也可攻击。
- 底部点选快捷栏。`BAG` 打开背包，点来源再点目标移动／合并／交换，`HALF ON/OFF` 切换拆分；箱子支持背包与容器转移。熔炉点来源物品后点输入／燃料槽，点输出槽取出。
- 制作栏点配方制作，顶部翻页；工作台须在附近。加工配方通过熔炉输入和燃料执行。菜单暂停物理、敌人和游戏时钟。
- 背包可切换生存／创造；创造目录先选快捷栏位置，再点物品。生存从空背包开始：原木 → 木板／木棍／工作台 → 木镐 → 圆石 → 石镐／熔炉 → 铁。
- `SAVE` 手动保存；有变化时每 30 秒自动保存。背包 `WORLD` 先保存再切换世界，SD 不可写时拒绝切换。开机默认世界 1。

## 存档

v4 单档 1,050,176 字节，保存地图、背包、工具、容器、加工、生长、重生点、昼夜及敌人状态；支持 v1/v2/v3 读取迁移。旧地图不会自动插入新矿物或洞穴，可进入另一世界生成新图。

- 世界 1：`MC0.SAV`／`MC1.SAV`；世界 2：`MC2.SAV`／`MC3.SAV`。双槽轮换、CRC 和写后回读校验。
- 单槽损坏时用另一个有效槽；无有效槽但发现异常文件，或发现未来版本时，保护为只读。没有 SD 仍可玩，断电不保留。
- `initial-world-v4.SAV` 是预览生成的示例，勿覆盖自己的存档。开发脚本的 `--sd G:/` 只读 SD。

## 构建与烧录

需要 Python 3.10+、ARM GNU 工具链和 STM32CubeProgrammer 的 SigningTool。仓库仅保留游戏构建实际使用的应用和 SDK 文件，不包含 ISP 库、IDE 缓存、固件和存档。原 CubeIDE 工程元数据仅作为源文件列表使用；以 Python 脚本构建为准。

```powershell
python tools/build_minicraft.py --toolchain "F:/path/to/arm-gcc/bin" --signer "F:/STM32CubeProgramer/bin/STM32_SigningTool_CLI.exe"
```

本机默认路径可省略参数。输出位于 `out/minicraft/`。编译定义 `MINICRAFT_GAME_ONLY` 排除未使用的相机 ISP，保留板级初始化。

| 输出 | 写入地址 |
| --- | --- |
| `MiniCraft_N6-Trusted.bin`（含 0x400 字节头） | **0x70100000** |
| `MiniCraft_N6.bin`（裸应用） | 0x70100400 |

两种应用文件选择一种烧录。沿用已正常启动本项目的 FSBL（地址 0x70000000，XIP 偏移 0x100000、头偏移 0x400）；本仓库不提供 FSBL 构建。首次配置开发板需先准备兼容该布局、完成 PSRAM／外部 Flash 初始化的 FSBL。

## 检查、预览与回溯

```powershell
python tools/test_minicraft.py --sd G:/
python tools/snapshot_minicraft.py
```

主机 GCC 以 `-Wall -Wextra -Werror` 验证几何、移动、采集、背包、合成、容器、熔炉、生长、战斗和存档；ARM 构建验证链接与签名。快照脚本在构建后生成源码 ZIP、固件副本、哈希与验证记录，保存到 `out/verified-v4/`。预览工具 `tools/minicraft_preview.c` 共用固件渲染器，可生成九种场景和界面图。

用户此前旧版板上约 15 FPS；**当前 v4 尚未烧录实测**。主机预览不能证明板上性能；触屏多指、LCD、真实 SD 迁移、异常断电和长时间运行仍需板验。

## 当前限制

火把仅直立，床仍为单格；敌人无寻路、跳跃、动画、战利品、独立洞穴生成规则和黎明消失。暂无饥饿、农业、动物、门、台阶、流体模拟、红石、音效与联网。采集物直接入包，没有地面掉落实体。
