# Third-party components

The repository includes only the SDK sources and headers used by the MiniCraft application build. Original copyright notices remain in each file. These components retain their respective licenses; this document does not relicense them.

| Component | Location | License / notice |
| --- | --- | --- |
| Arm CMSIS | `Drivers/CMSIS` | `Drivers/CMSIS/LICENSE` (Apache-2.0), plus notices in source files |
| ST STM32N6 device support | `Drivers/CMSIS/Device/ST/STM32N6xx` | `LICENSE.txt` in that directory |
| ST STM32N6 HAL | `Drivers/STM32N6xx_HAL_Driver` | `LICENSE.txt` in that directory |
| Microsoft Azure RTOS FileX, distributed with the ST SDK | `Middlewares/ST/filex` | `LICENSE.txt` and `LICENSED-HARDWARE.txt` in that directory |

The bundled FileX licensed-hardware list explicitly includes STM32N6 Series. Preserve its license and hardware list when redistributing these files. Board initialization and FileX glue derived from the original STM32 project retain their source notices. No camera ISP binary library is required or included in the game build.

MiniCraft item graphics are generated by `tools/make_minicraft_icons.py`; they do not contain downloaded Minecraft textures.
