# Third-party components

The repository includes only the SDK sources and headers used by the MiniCraft application build. Original copyright notices remain in each file. These components retain their respective licenses; this document does not relicense them.

| Component | Location | License / notice |
| --- | --- | --- |
| Arm CMSIS | `Drivers/CMSIS` | `Drivers/CMSIS/LICENSE` (Apache-2.0), plus notices in source files |
| ST STM32N6 device support | `Drivers/CMSIS/Device/ST/STM32N6xx` | `LICENSE.txt` in that directory |
| ST STM32N6 HAL | `Drivers/STM32N6xx_HAL_Driver` | `LICENSE.txt` in that directory |
| Microsoft Azure RTOS FileX, distributed with the ST SDK | `Middlewares/ST/filex` | `LICENSE.txt` and `LICENSED-HARDWARE.txt` in that directory |

The bundled FileX licensed-hardware list explicitly includes STM32N6 Series. Preserve its license and hardware list when redistributing these files. Board initialization and FileX glue derived from the original STM32 project retain their source notices. No camera ISP binary library is required or included in the game build.

MiniCraft item graphics are generated by `tools/make_minicraft_icons.py`; they do not contain downloaded Minecraft textures.

The embedded Chinese glyph subset in `Appli/Core/Inc/mc_zh.h` is derived from Noto Sans SC (Google Fonts), Copyright 2014-2021 Adobe, under SIL Open Font License 1.1. The complete notice and license are in `assets/minicraft/NotoSansSC-OFL.txt`. The subset is generated by `tools/make_minicraft_zh.py` using only the UI characters; no full upstream font is included in the repository. Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc . The glyph data retains its OFL license; original item graphics are separate project assets.

Chinese UI font correction (v23): normal 16px glyphs use Noto Sans SC at explicit weight 500. Compact 12px glyphs use the Simplified Chinese Ark Pixel monospaced 12px build 2026.10.16, Copyright (c) 2021 TakWolf, SIL OFL 1.1; its complete license is in `assets/minicraft/ArkPixel-OFL.txt`. The one absent used character U+71C3 uses Noto Sans SC weight 500 at 12px. Only used glyph subsets are embedded. Pinned font source URLs, zip member and SHA-256 hashes are in `tools/minicraft_font_sources.json`; full downloaded fonts remain under out. Upstream Ark Pixel: https://github.com/TakWolf/ark-pixel-font/releases/tag/2026.10.16 .
