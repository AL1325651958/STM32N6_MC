# MiniCraft 简中字库逐字检查（v28）

此前 Noto Sans SC 可变字体默认字重为 100，直接二值化后细笔画大量丢失。现将 16px 字形固定为字重 500；12px 使用原生 Ark Pixel 简中字形，避免缩小矢量细线。Ark 缺少的“燃”（U+71C3）显式使用 Noto 500 备用字形。

当前 306 条词条共使用 349 个汉字，两种字号共 698 个字形。每字均检查源字体 cmap 映射（禁止 .notdef）、非空位图、带留白画布外溢、行掩码与固件 UTF-8 绘制像素；同一字符大小字形均留存。八页字形表逐格目视巡检，显示原尺寸和 2 倍最近邻放大，不使用平滑滤镜。屏幕物理观感仍待开发板复测。

生成器：`tools/make_minicraft_zh.py`；固件绘制回归：`tools/minicraft_font_test.c`；来源版本和哈希：`tools/minicraft_font_sources.json`。检查报告及实际绘制的八页 `glyphs-01.png` 至 `glyphs-08.png` 保存在 `out/verified-v28/latest`。每格左侧 16px，右侧 12px；上方是 2 倍放大，下方为原像素。

重新生成需 Pillow、fontTools 与 out 下已下载字体：

```text
python tools/make_minicraft_zh.py --font out/minicraft/fonts/NotoSansSC.ttf --pixel-font out/minicraft/fonts/ark-pixel-12px-monospaced-zh_hans.ttf --check
python tools/test_minicraft.py --sd G:/
```

完整字体不上传；固件和主机 C 测试使用已生成的内置子集，无需字体文件或 SD 字库。新词条引入不在原生小字库中的字符时，生成器会失败，必须人工核对并显式决定备用字形。
