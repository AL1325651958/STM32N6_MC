# MiniCraft v3 使用与构建

## 当前版本

游戏运行在 STM32N6570-DK，使用 128 x 64 x 128 方块世界和 800 x 480 触屏界面。世界以 160 x 96 软件画面渲染。生存模式提供 32 格背包，前 8 格为快捷栏；创造模式提供无限方块目录。

## 触屏操作

- 左下摇杆区域：移动。拖动其他画面区域：转动视角。
- 画面上对准目标按住 450 ms：开始挖掘，随后按硬度和工具耗时；移动手指超过 12 px 会重新计时。快捷栏选中工具后，长按挖掘会使用该工具。挖掘按钮已移除。
- 右侧 `USE`：对准工作台、箱子、熔炉或床时交互；其他时候使用食物、选择工具或放置方块。
- 右侧 `JUMP`：跳跃；顶部 `BAG`：打开/关闭背包；`SAVE`：手动保存。
- 右侧 `SNEAK`：按住潜行，速度降至 35%，贴近平台边缘时会阻止玩家走下无支撑的地面；松开后恢复普通移动。跳跃和已经在空中时仍可离开平台。
- 背包中点一个槽位再点另一个槽位移动物品。`HALF ON` 开启后拆分堆叠。点背包槽位再点箱子槽位转存；选中物品后点熔炉输入/燃料槽，点输出收取成品；选中空背包格再点输入/燃料可取回剩余物料。非空箱子/熔炉不可挖毁，熔炉还需等火燃尽。
- 对准工作台按 `USE` 打开制作界面，也可从 `BAG` 打开；共 17 个配方，按右上方 `NEXT` 翻页。需要工作台的配方会检查附近是否有工作台。
- 床在夜间可跳到早晨并设置重生点。苹果在受伤时使用，可恢复最多 5 点生命。

## 当前规则

- 每格普通物品最多 64 个；工具独立成格且分别记录耐久。背包满时不会破坏方块或丢失掉落物。
- 背包、快捷栏、箱子、熔炉与配方均显示各物品的像素图标；图标由工具生成并编入固件 ROM。
- 世界内火把细杆宽 2/16 格、高 10/16 格，火焰由 4/16、3/16、2/16 宽的阶梯部件组成；树苗使用有透明轮廓的交叉面；床高 9/16 格，箱子宽深 14/16 格、高 14/16 格。选取、挖掘和实体碰撞跟随实际形状，火把与树苗可穿过。火把目前为直立造型，床仍占一格，暂不含壁挂方向与双格床。
- 熔炉每件物品加工 5 秒：铁矿变铁锭、沙子变玻璃、圆石变砖、原木变煤。燃料支持煤、原木和木板。
- 树叶掉落树苗的概率为简化确定性规则；树苗需种在泥土/草地，120 秒后在空间足够处长成树。
- 床配方暂用 3 木板和 3 树苗替代羊毛；剑目前还没有攻击/敌人系统。
- 存档 v3 含完整背包和容器状态，可读取 v1/v2；SD 使用双槽 CRC 写入。自动保存间隔为 30 秒，切换世界前也会保存。
- v1 存档按创造模式导入；v2 物品迁移到槽位，超出背包容量的旧物品会保留，腾出空格后逐步恢复。主机测试不会重写 SD 旧档；板上后续保存将写为 v3。
- 地图本轮仍为 128×64×128；更大世界的分块加载尚未实现。

## 构建和验证

打开背包时移动、伤害与昼夜暂停，熔炉和树苗继续更新；离线不加工。单次超长帧的模拟时间上限为 0.1 秒。

在工程根目录运行：

```powershell
F:\Python310\python.exe tools/test_minicraft.py --sd G:/
F:\Python310\python.exe tools/build_minicraft.py
```

测试脚本只读 `G:/MC0.SAV` 至 `G:/MC3.SAV`（若存在），不会写入 SD。固件下载地址为 `0x70100000`，构建产物是 `out/minicraft/MiniCraft_N6-Trusted.bin`。烧录后请验证冷启动、背包/箱子/熔炉触控、保存重启恢复和 FPS；目前新版尚无板上测量结果。HUD 会显示平均 FPS、最长帧毫秒数和手动存档耗时。

本次固件由上述 Python 构建脚本验证。CubeIDE 的旧 `Debug` 生成文件可能缺少新增源文件；使用 IDE 前请刷新工程并重新生成构建文件，再执行 Clean/Build。
